# BetterMC6_clientAndServerMods
This is a repository for BetterMC6 mods. It is supposed to divide them into client and server mods so you can easily create a self hosted dedicated minecraft server without having to manually find client server mods and taking them out from the server. I'm not a creator of the mods nor am I affiliated with them

# Important
The repository splits mods that can be on a client and on a server. It doesn't automatically mean that the one from the server one can't be on the client one. It's just splited like that so you don't have to split them manually. If you just copy these ones to your server and client mods fodler it'll just work. Client folder also has files from the server folder but not vice versa.
